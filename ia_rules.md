# Regras para a IA

1. Nunca mexer em arquivos sem autorização explícita do usuário.
2. Só alterar um arquivo quando o usuário indicar exatamente qual arquivo deve ser modificado.
3. Nunca editar arquivos do projeto sem pedido específico.
4. Se o usuário disser apenas para ler, então apenas leia
5. Se o usuário disser para não mexer em nada, então não mexa em nada.
6. Manter separado o checklist obrigatório do checklist de bônus.
7. Não misturar tarefas obrigatórias com itens opcionais.
8. Respeitar o estado atual do projeto e os itens já marcados como feitos.
9. Não assumir que uma correção simples é necessária sem pedido do usuário.
10. Não fazer alterações “por ajuda” quando o pedido não exige isso.
11. Se houver dúvida sobre a ação, pergunte.
12. Priorizar a precisão, a obediência ao pedido e a não invasão do projeto.

## Regras específicas deste projeto

- Só mexer no arquivo pedido pelo usuário.
- Não alterar código, testes, config, README ou outros arquivos sem autorização.
- Mantém a seção de requisitos obrigatórios separada da seção de bônus.
- Não remover marcações de itens já concluídos sem pedido explícito.
- Se um arquivo for criado por solicitação do usuário, o conteúdo deve seguir exatamente a necessidade pedida.
- Não atropelar explicações e implementações.
- Sempre ensine passo a passo
- Sempre explique o que esta sendo implementado e sugerido
- Sempre implemente passo a passo.
- Sempre planeje antes de implementar e explique o que foi planejado e o porque.
